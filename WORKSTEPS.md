### Hour 2–8: Backend Core
**Person A**

#### FastAPI Setup
- [ ] Create `backend/main.py` — mount all routers, add CORS middleware
- [ ] Create `/health` endpoint to verify service is alive

#### Single Prediction Endpoint (`POST /predict`)
- [ ] Load `model_delay.json` and `model_risk.json` on startup
- [ ] Accept input: `origin`, `destination`, `cargo_type`, `shipment_date`, `transport_mode`
- [ ] Run XGBoost inference → get `delay_days` + `risk_level`
- [ ] Run SHAP → get top 3–5 feature contributions as percentages
- [ ] Return structured JSON:
  ```json
  {
    "delay_days": 3.8,
    "risk_level": "HIGH",
    "confidence": 0.82,
    "shap_breakdown": {
      "port_congestion": 0.45,
      "weather_index": 0.30,
      "route_distance": 0.15
    },
    "action_plan": null
  }
  ```

#### Gemini Integration (`services/gemini_service.py`)
- [ ] Build prompt template that takes XGBoost output + SHAP breakdown as input
- [ ] Call `gemini-1.5-flash` (fast and free tier friendly)
- [ ] Parse response → return as `action_plan` string in the predict response
- [ ] Prompt template (example):
  ```
  You are a logistics risk advisor. Given this shipment data:
  - Risk Level: HIGH
  - Predicted Delay: 3.8 days
  - Top Risk Factors: Port Congestion (45%), Bad Weather (30%)

  Write a concise action plan (3 bullet points max) for the shipper.
  Be specific and practical. Do not re-state the numbers.
  ```

---

### Hour 8–14: Bulk Upload Endpoint
**Person A**

#### `POST /predict-bulk` — CSV Batch Prediction
- [ ] Accept multipart file upload (`.csv` or `.xlsx`)
- [ ] Parse file using `pandas.read_csv()` / `pd.read_excel()`
- [ ] Validate columns — return clear error if required columns are missing
- [ ] Run prediction loop for each row
- [ ] Return array of results:
  ```json
  {
    "total": 30,
    "results": [
      { "row": 1, "origin": "Batam", "destination": "Singapore", "risk_level": "HIGH", "delay_days": 4.2 },
      ...
    ],
    "summary": { "high": 8, "medium": 15, "low": 7 }
  }
  ```
- [ ] Limit: max 200 rows per upload

#### Feedback Endpoint (`POST /feedback`)
- [ ] Accept: `prediction_id`, `was_delayed` (bool)
- [ ] Save to Supabase `feedback` table
- [ ] Return `200 OK`
